# Lesson GCal Sync for Kimini

Kimini英会話で予約したレッスンを、Googleカレンダーに自動で登録するChrome拡張機能。
予約をキャンセルすれば、カレンダーからも消える。

> **非公式ツールです。** Glats Inc. および学研グループとは関係ありません。

## できること

- レッスンを予約すると、Googleカレンダーに予定が入る（講師名・コース名・教材名・詳細ページへのリンク付き）
- 予約をキャンセルすると、カレンダーからも予定が消える
- 別の環境で予約した分も、ボタンひとつでまとめて取り込める
- 同じ予約が重複して登録されることはない

## 使いはじめる

```sh
git clone https://github.com/otokichi3/kimini-plus.git
```

1. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」で、clone したフォルダを選ぶ
3. ツールバーの拡張機能アイコンを押し、「Googleアカウントを連携」を押す

Google Cloud の設定は要らない。OAuth クライアントは同梱の設定を共有している。

連携時に「このアプリは Google で確認されていません」と表示される。Google の審査を受けていないためで、
「詳細」→「安全でないページに移動」で進める。通信先は Google カレンダーと Kimini だけ。

あとは普段どおり Kimini でレッスンを予約すれば、カレンダーに入る。

## 別の環境で予約したとき

この拡張機能は Kimini のページを開いたときに動くため、別の Chrome プロファイルやスマートフォンで
予約した分はそのままでは取りこぼす。

ツールバーの拡張機能アイコンから「予約済みのレッスンを取り込む」を押すと、未登録の予約をまとめて登録し、
キャンセルされた分も削除する。その Chrome プロファイルで Kimini にログインしている必要がある。

## 設定

ツールバーの拡張機能アイコンから変更できる。

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| 自動登録 | オン | オフにすると何もしない |
| カレンダーID | `primary` | 別のカレンダーに入れたい場合に指定する |
| タイトル | `Kimini英会話 - {teacher}` | `{teacher}` `{course}` `{material}` が使える |
| 通知 | 10分前 | `-1` にすると通知を設定しない |

## 注意

- 動作確認はニューストークコース（スタンダードPlusプラン）・PC の Chrome のみ。他のコースでは教材名などが空欄になることがある
- 削除するのは、この拡張機能が登録した予定だけ。手で作った予定には触らない
- 開始時刻を過ぎたレッスンは削除しない

## 構成

```
manifest.json      拡張機能の定義。OAuth クライアント ID もここにある
src/content.js     Kimini のページから予約を読み取る
src/background.js  Google カレンダーに登録・削除する
src/popup.html     ツールバーから開く画面
src/popup.js
```

## 開発者向けのメモ

`manifest.json` の `key` は拡張機能 ID を `nngimhenmgcebojjiolkmpgehgpndnpf` に固定するためのもの。
OAuth クライアントはこの ID に紐づいているので、消さないこと。

Google Cloud（プロジェクト `otokichi-app`）には Calendar API の有効化、外部向け OAuth 同意画面、
スコープ `calendar.events`、種類「Chrome 拡張機能」の OAuth クライアントを設定してある。
未検証アプリのため、ユーザー数の上限は累計100人。

秘密鍵 `key.pem` は `../kimini-plus-keys/` に置いてある。`.crx` に署名するときにだけ使う。
失うと同じ ID で作り直せず OAuth クライアントも作り直しになるので、捨てないこと。
